# MemoryMesh v0 — Lead Magnet Edition

MemoryMesh v0 is intentionally small.

The goal is not to build the full cloud platform yet. The goal is to prove that developers and AI builders want a simple, model-agnostic memory layer for agents.

## Current promise

```txt
Make AI agents remember safely.
```

## What v0 is

- A public GitHub repo that explains the pain clearly
- A local-first REST API scaffold
- A TypeScript SDK scaffold
- An MCP server scaffold
- A visual README that makes the project easy to understand
- A Cloud waitlist offer with clear free limits

## What v0 is not

- Not a production hosted memory cloud yet
- Not an enterprise security product yet
- Not a full vector database replacement
- Not a full AI agent framework

## Free Cloud offer to validate demand

```txt
1 hosted project
1 API key
1,000 memories
100 searches/day
30-day retention
REST API + SDK + MCP access
No credit card planned for the free tier
```

## Validation target

Move forward only if at least one of these happens:

- 10+ GitHub stars from real developers
- 5+ waitlist signups
- 3+ people ask for hosted API access
- 1+ company asks about team memory or audit logs
- 1+ developer opens an issue requesting an integration

## Next version trigger

If the validation target is reached, build v0.1 Cloud Preview:

- API key auth
- hosted project creation
- Postgres persistence
- basic memory dashboard
- waitlist invite flow
- usage limits
- upgrade CTA

## Commercial angle

```txt
Open source earns trust.
Cloud converts production usage.
```

Free is for experiments. Paid is for hosted storage, retention, audit logs, team memory, MCP cloud sync, and production reliability.

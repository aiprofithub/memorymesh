# MemoryMesh Cloud

MemoryMesh Cloud is the hosted version of MemoryMesh for developers and teams that do not want to operate their own memory infrastructure.

## Positioning

```txt
Persistent memory for production AI agents — with consent, audit trails, and safe forgetting.
```

## Free plan

The free plan is designed to make developers feel the value quickly.

```txt
1 project
1 API key
1,000 memories
100 searches/day
1 agent
30-day retention
Community support
```

## Paid upgrade reasons

Users should upgrade when:

- their agent depends on memory in production
- they need more memory capacity
- they need longer retention
- they need more agents
- they need team/workspace memory
- they need audit logs
- they need MCP cloud sync
- they need support

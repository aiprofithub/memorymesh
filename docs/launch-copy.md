## Developer-focused post

```txt
Most AI agents are stateless by default.

I built MemoryMesh v0 to test a simple idea:
AI agents need a shared memory layer that is model-agnostic, explicit, searchable, and forgettable.

The repo includes a REST API scaffold, TypeScript SDK scaffold, MCP server scaffold, and a local-first memory schema.

I am not building the full cloud yet. First I want to see if builders actually want this.

Feedback welcome:
https://github.com/aiprofithub/memorymesh
```

# MemoryMesh positioning

## One-liner

Universal memory hub for AI agents, copilots, and AI-native apps.

## Developer positioning

Model-agnostic memory infrastructure for persistent AI agents. Connect through REST, SDK, MCP, and webhooks.

## Business positioning

A permissioned memory control layer that lets companies reuse AI context safely across agents, teams, and workflows.

## What makes it different

MemoryMesh is not just vector search. It combines memory storage, retrieval, consent, audit logs, lifecycle controls, and agent handoff.

## Wedge

Start with developer adoption: TypeScript SDK + REST + MCP.

Then move into enterprise value: memory firewall, audit trail, deletion/export, team memory graph, and compliance-ready receipts.

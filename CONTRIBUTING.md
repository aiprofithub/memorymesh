# Contributing to MemoryMesh

MemoryMesh is currently in v0 Lead Magnet Edition.

The goal is simple: validate whether developers want a small, model-agnostic memory layer for AI agents before building a larger cloud product.

## Good contributions for v0

- small examples
- clearer docs
- API key auth
- local persistence
- MCP search tool
- SDK examples
- bug fixes

## Not needed yet

- billing
- enterprise SSO
- large dashboard
- complex vector pipeline
- advanced team permissions

## Local setup

```bash
pnpm install
pnpm dev
```

API default:

```txt
http://localhost:4310
```

## Contribution style

Keep pull requests small.

Good PR shape:

```txt
1 feature
1 clear use case
1 short docs update
```

## Project principle

Memory should be explicit, inspectable, forgettable, and portable.

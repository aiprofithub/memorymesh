A memory control plane, not another chatbot.

Most agents get worse when context disappears or prompts get bloated. MemoryMesh keeps memory explicit, searchable, and portable.

R

Remember explicitly

Store user preferences, decisions, project context, and previous handoffs without silently saving everything.

S

Search safely

Retrieve relevant memory by user, agent, project, scope, or query instead of stuffing raw chat history into every prompt.

F

Forget by design

Build around deletion, retention, export, and memory receipts from day one. Memory should not be a black box.

⚡

Local-first v0 demo.

Clone the repo, run the API, create a memory, then search it. No hosted cloud required for testing.

  • Fastify REST API
  • TypeScript SDK scaffold
  • MCP server scaffold
  • In-memory local store
git clone https://github.com/aiprofithub/memorymesh.git
cd memorymesh
pnpm install
pnpm dev

# API
GET  http://localhost:4310/
POST http://localhost:4310/v1/memories
GET  http://localhost:4310/v1/memories/search?q=thai
